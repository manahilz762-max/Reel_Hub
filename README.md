# Reel_Hub

**University Media & Creative Team Website**

Reel_Hub is a React and Vite-based website showcasing university events, photography, videography, creative portfolios, and campus stories.

## Features

- University media team introduction
- Event photography and video galleries
- Official and unofficial event sections
- Team member portfolios
- Daily blogs and campus stories
- Responsive website design

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Framer Motion
- Lucide React

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
